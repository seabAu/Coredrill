## Implemented boundaries

- Application version-1 preview/commit/discard contracts strictly rebuild and freeze byte/path-free metadata. The runtime retains one private full-archive coordinator capability, binds the original viewed vault (including explicit empty target), exact archive/target tuple and fresh target fingerprint, and rejects drift, foreign identities, replay and concurrent operations. Selection/preview never commits.
- Normal Settings restore shares the existing root-owned export/deletion/reminder mutation mutex, including the whole asynchronous file read. Browser file sizes are bounded before reading; native selection uses only the Rust-owned bounded complete-archive input, never a browser fallback.
- UI presents archive/target IDs, schema, hashes, counts, exact database/reference changes and different/same-vault warnings. Confirmation starts unchecked and is derived from the retained exact preview. Discard retires the capability; root disposal retires late preview results without publishing to an abandoned view. Navigation/reflow do not replace the controller.
- Onboarding restore hides but preserves unsaved setup forms and guards setup persistence synchronously. Back requires acknowledged preview retirement. Commit attempts transition to a local-reopen view, not potentially stale canonical UI. An uncertain acknowledgement is never automatically retried or described as unchanged data.
- Normal restore opts into adapter retirement inside the held storage queue slot on success/failure. Old queued writes cannot execute after replacement, including same-vault replacement. Generic backend restore retains its previous non-retiring behavior unless explicitly opted in. Browser selected bytes/target options are captured before queue entry, and restore acknowledgements strictly match schema/length/digest and the requested identity.
- No database schema, archive format, native permission, dependency version or Accepted decision changes. A Changeset records package behavior. Native input's measured negated-reference matcher repair is included without changing data sizes, assertions of ownership/content, production parser or timeouts.
