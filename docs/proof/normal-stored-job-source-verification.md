## Read lifetime and recovery

One active read action owns loading through all of its pane reads settling, including early failure of one concurrent read. Invalid job/snapshot echoes fail closed. Retry retains old evidence with an explicit stale warning and content-free message; stale content/value continuations restart from the first part instead of silently concatenating incompatible chunks. Disposal prevents further downstream reads and late publication. Selected pane metadata may remain visible while paging history; its label identifies the earlier history read. Explicit Reload newest resets selection, and first evidence-page reload is separate. Vault deletion disables/disposes the Source reader.

Source focus restoration is requested after the corresponding React layout commit, still subject to the existing interaction-ownership guard, and cancelled when reader ownership changes. It does not claim to diagnose or repair the unrelated historical Table focus failure.
