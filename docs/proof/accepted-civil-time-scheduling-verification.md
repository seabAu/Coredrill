## Implemented behavior

- `apps/web/src/local-schedule.ts` validates literal four-digit Gregorian dates and minute/optional-second/exact-millisecond clock precision, canonicalizes a bounded IANA zone and returns only copied/frozen UTC string candidates. Offsets, annotations, leap seconds, implicit device zones and unsupported precision are rejected, not truncated or coerced. Earlier/later interpretations whose local clock differs are discarded. Zero candidates rejects a gap; one is unique; two require deliberate occurrence selection. Conversion beyond the durable year range rejects.
- `local-schedule-loader.ts` imports that helper only on explicit scheduling use. It is single-flight and owner-disposable; late success/failure cannot publish to a retired owner. No task data enters the module loader and no network fallback resolves clocks.
- Normal Set next action keeps the original viewed job/version and literal title/clock/zone in its existing root-owned session draft. Clock/zone/mode edits clear prior resolution and occurrence. Exact canonical zone, offset and UTC candidates are reviewed before saving. Existing application/storage creation, earliest-pending projection, shared feedback and undo remain authoritative; existing tasks are retained.
- Scheduled controls share unscheduled ownership rules, stale rejection, acknowledgement lock, failure retention, original-context retry and deliberate focus recovery. Readback failure must refresh reads rather than repeat writes. A due task is not a notification or employer outreach.
- A real failed-module probe demonstrates that Chromium caches the failed import within its document. A same-page Retry did not refetch and is not falsely offered as recovery. The UI retains input, explains the limitation and loss on reload, offers an explicit reload through the existing cancellable unsaved-input warning, or lets the user deliberately turn off scheduling and save an unscheduled task. There is no silent fallback or automatic retry/write. Fresh reload subsequently loads the helper normally.
