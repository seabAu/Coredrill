Add the version-1 canonical document IR, restricted local Tiptap editor, deterministic
round-trip and paste sanitation, source-mapped local DOCX, PDF, and text import
proposals, controlled accessible DOCX output, and tagged semantic PDF print output with
explicit scanned-file and failure handling.

Compatibility: this establishes document IR version `1`; later schema versions and
import/export adapters must preserve source mappings and must never silently convert
imported proposals into user-confirmed evidence.
